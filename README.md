
# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I, do IFPB - Campus Campina Grande.

## Integrantes

- Kimmel Dinis Leão

## Como jogar

O computador escolhe uma palavra aleatoriamente e o jogador precisa descobrir qual é a palavra secreta.

Digite uma letra por vez e clique em Tentar.

As letras corretas serão reveladas nas posições correspondentes. As letras incorretas diminuirão a quantidade de tentativas.

O jogador possui 6 tentativas para descobrir a palavra.

Não é permitido utilizar a mesma letra mais de uma vez.

O jogo termina quando o jogador descobre a palavra ou quando as tentativas acabam.

Clique em Nova partida para começar novamente.

Também é possível enviar uma letra pressionando a tecla Enter.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Escolha aleatória de palavras.
- Palavra inicialmente escondida.
- Revelação das letras corretas.
- Controle de tentativas.
- Identificação de letras incorretas.
- Lista de letras utilizadas.
- Bloqueio de letras repetidas.
- Mensagem de vitória.
- Mensagem de derrota informando a palavra secreta.
- Reinício da partida.
- Envio de letras utilizando a tecla Enter.
